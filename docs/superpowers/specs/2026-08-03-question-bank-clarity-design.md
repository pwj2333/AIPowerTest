# Question Bank Clarity and Option Randomization Design

## Goal

让 20 道 AI 能力测评题对领导和普通员工都直白易懂，同时让答案长度和位置都不能泄露分值。

## Requirements

- 保留现有题目 ID、等级、能力维度和 0–3 分评分键，避免影响历史答案和评分逻辑。
- 20 道题的题干使用具体工作任务和明确动作，避免只对熟悉 AI 术语的人可读。
- 每个答案选项严格为 18 个 Unicode 字符，四个选项长度完全相同；18 落在用户要求的 15–20 字范围内。
- 默认题库与 Markdown 导入都校验统一长度；任一答案长度不符时拒绝保存。
- 员工端按受测者和题目生成稳定伪随机排列，返回上一题或刷新后顺序保持不变，避免已选答案错位。
- 随机排列必须保证 3 分选项不在最后一项，并且不同受测者的 3 分位置可以变化。

## Architecture

`src/domain/questions.ts` 负责直白题库、统一长度常量和 Markdown 校验。选项的评分键仍绑定选项 ID，解析和序列化保持不变。

`src/components/QuestionCard.tsx` 负责员工端展示顺序。使用现有的种子洗牌算法，对每个题目生成受测者稳定的排列；若 3 分选项落在末项，则交换末项与前一项。该排列只影响显示，不改变答案 ID 和计分。

## Testing

- 题库测试断言恰有 20 道题、覆盖 0–3 分、所有选项都为 18 字且每题四项长度相同。
- 导入测试断言长度不符、3 分位于末项的内容会被拒绝。
- 组件测试断言同一 seed 顺序稳定、不同 seed 能产生不同顺序、3 分选项永不位于末项。
- 完成全量 Vitest、生产构建，并检查工作区状态。
