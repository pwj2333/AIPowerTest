# AI 能力认证 Web 调研问卷设计

## 目标

面向全体员工提供一次 8-12 分钟的 AI 能力测评。员工立即获得与能力金字塔一致的 1-8 级结果、短板和行动任务；管理员据此查看部门、岗位的能力分布和培训重点。

本系统用于个人能力成长和组织培训诊断，不单独作为绩效或人才筛选的依据。

## 已确认的产品决策

- 沿用 8 级能力塔：L1 青铜、L2 白银、L3 黄金、L4 铂金、L5 钻石、L6 星耀、L7 王者、L8 荣耀王者。
- 全员使用同一套固定 20 题问卷，不采用自适应出题或自选等级。
- 仅采用问卷，不要求提交作品或现场实操；结果名称为“AI 能力测评等级”，不是严格技能认证。
- 管理员导入姓名、部门、岗位后，系统生成专属、可追踪的测评链接；每名员工在一个批次中只能提交一次。
- 结果页只提供行动任务，不维护课程、培训班或外部学习资源库。
- 首版只有一种管理员角色；管理员不能手工修改系统得分。

## 能力模型与题库

所有题目为工作情景题，题干描述任务、资料、协作对象或限制条件，四个选项代表不同的行为成熟度。题目可列举 DeepSeek、Kimi、扣子、知识库或低代码工具作为例子，但评分只判断等效能力，不绑定某个具体产品。

| 题号 | 等级 | 能力判断 |
| --- | --- | --- |
| 1-2 | L1 青铜：会问 AI | 为任务选择合适的对话工具；清楚表达目标、背景、约束和输出格式。 |
| 3-5 | L2 白银：会用 AI 办公 | 基于材料生成办公交付物；验证结果；迭代提示词并处理错误。 |
| 6-8 | L3 黄金：会找 AI 场景 | 识别适合 AI 的任务；定义输入、产出、风险、验收标准和人工边界。 |
| 9-11 | L4 铂金：会训练 AI 流程 | 拆解高频任务；配置可复用流程；处理异常、版本和人工审核。 |
| 12-14 | L5 钻石：会连接 AI 工具 | 连接知识库、文件或协作工具；设计权限、更新机制和交付链路。 |
| 15-16 | L6 星耀：会搭建 AI 应用 | 通过可视化或低代码制作可访问的小应用；测试并根据反馈迭代。 |
| 17-18 | L7 王者：会重构业务流程 | 用 AI 改造团队工作方式；定义采用率、效率或质量等业务成效。 |
| 19-20 | L8 荣耀王者：会建设 AI 生态 | 沉淀课程、平台、标准或案例体系，并推动可复制的组织级应用。 |

### 定级与置信度

- 每个选项配置 `0-3` 行为成熟度分，并关联一个能力维度和等级题组。
- L1 是最低显示等级。L2-L8 按顺序判定：当前等级题组的平均分必须达到 `2`，且所有前序等级题组也必须达到 `2`；不允许跳级。
- 题库还配置一组相互印证的情景，检测明显的高低阶能力矛盾。
- 若答题时间低于可配置阈值（默认 3 分钟）、同一选项连续选择超过 75%，或触发能力矛盾，则结果标为“低置信度”。低置信度不自动降级，但在个人结果与管理员列表中明确显示；L6-L8 同时列为“建议复核”。
- 每次测评批次绑定一个题库和评分规则版本。已完成结果不可被新版规则覆盖，复测必须创建新批次。

## 员工端

### 页面与流程

1. 员工通过专属链接进入。系统带出姓名、部门、岗位，并显示用途、隐私说明和预计时长。
2. 每屏显示 1 题，共 20 题；顶部显示进度和题号。可返回修改，系统自动保存已答内容。
3. 提交后即时计算结果。再次访问专属链接时，只能查看自己的结果，不能在同一批次重复作答。
4. 结果页展示当前等级徽章、能力解释、四维表现、置信度、2-3 个主要短板，以及下一阶段的 3 个行动任务。

### 行动任务规则

系统从低分维度中优先选取任务，同时结合当前等级生成下一阶段的实践路径：

| 当前等级 | 主要行动任务 |
| --- | --- |
| L1 | 用“目标-背景-要求-输出格式”模板完成一个实际提示词，并比较修改前后的结果。 |
| L2 | 用一份非敏感材料完成总结、通知或纪要，并逐项核验事实和数据。 |
| L3 | 为一个高频任务写出输入、输出、风险、人工审核和验收标准。 |
| L4 | 把一个验证过的场景拆成可复用流程，标出异常分支和人工检查点。 |
| L5 | 在权限允许的前提下，把非敏感资料接入知识库或协作工具并完成一次团队交付。 |
| L6 | 用低代码或可视化工具搭建一个面向同事的小应用，收集反馈后迭代。 |
| L7 | 选择一个团队流程开展 AI 改造试点，并记录采用率、效率或质量变化。 |
| L8 | 沉淀可推广的标准、案例或课程，建立复用与反馈机制。 |

L8 的结果页显示“保持与复制”任务，不再显示不存在的下一等级。

## 管理员端

### 功能结构

- **概览**：参测率、平均等级、8 级分布、部门和岗位对比、四维短板、待复核结果。
- **测评批次**：创建、开启、关闭和归档批次；查看每批次的题库版本和参与进度。
- **人员名单**：导入 CSV 名单，字段为姓名、部门、岗位；校验缺失字段和重复人员；生成并导出专属链接。
- **结果明细**：按部门、岗位、等级、完成状态和置信度筛选；查看单人结果和行动任务，不编辑得分。
- **题库与规则**：维护题目、选项、能力维度、等级题组、评分和矛盾校验；题库发布后生成新版本。
- **数据导出**：导出个人明细、部门/岗位汇总、等级分布和短板汇总。

### 管理流程

`创建批次 -> 选择题库版本 -> 导入名单 -> 生成/分发链接 -> 员工答题 -> 自动定级 -> 管理员查看分析与导出 -> 创建下一批次复测`

## 核心数据与规则

- `AssessmentCampaign`：测评批次、状态、截止时间、题库版本。
- `Participant`：员工姓名、部门、岗位和批次归属。
- `Invitation`：专属访问令牌、访问状态、完成状态和访问时间；完成后保留查看结果的权限。
- `Question` / `QuestionOption`：场景题、选项、分值、能力维度、等级题组与版本。
- `Response`：逐题答案、修改时间和总答题时长。
- `AssessmentResult`：等级、各维度得分、置信度、短板、行动任务和待复核标记。

名单导入失败时，系统应逐行报告原因，且不写入未通过校验的数据。链接失效、批次关闭、重复提交、网络中断恢复和答题未完成都需要有明确状态和可理解的提示。题干不要求员工上传业务资料；如在示例中提到资料或知识库，应提示使用非敏感且已获授权的内容。

## 视觉与交互原则

- 将能力塔的金色徽章作为等级识别，主界面采用深蓝、白色和克制的蓝色数据强调，避免将企业工具界面做成游戏化页面。
- 员工端一题一屏，减少干扰；结果突出当前能力、下一步和可执行任务。
- 管理员端采用高信息密度的导航、表格和图表，优先支持筛选、比较和批量操作。

## 验收场景

1. 管理员导入包含姓名、部门、岗位的名单后，能获得每名员工唯一且可追踪的测评链接；重复和缺失数据被逐行提示。
2. 员工可在 8-12 分钟内完成 20 题，刷新或返回后已答内容不丢失；同批次提交后不可再次答题。
3. 同一组答案在同一题库版本下始终得到相同的等级、维度、行动任务和置信度；不能绕过前序门槛获得高等级。
4. 低置信度和 L6-L8 结果在个人端与管理员端都有清晰提示，且不允许管理员直接改分。
5. 管理员能按部门和岗位查看参测率、等级分布、能力短板和个人明细，并导出明细与汇总。
6. 新建复测批次不会改变已有批次的答案、结果或题库版本。

## 不在首版范围内

- 作品提交、人工阅卷、现场实操或严格技能认证。
- 企业单点登录、复杂的多角色权限体系和课程/培训班管理。
- 根据员工前序答案动态出题。
- 管理员手工改分或将结果直接用于绩效考核。
